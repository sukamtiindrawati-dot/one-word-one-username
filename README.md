Entry for the make.fun bounty "One Word, One Username, One Reward"
(`u-rusdyxbt-one-word-one-username-one-reward-1a191fae`).

The bounty asks for the entrant's own make.fun username, one word and nothing
else. `main.py` scores a shortlist of candidate handles against the judge's
published criteria — genuine handle first, then smile on first read,
memorability, single word, wearability — and writes the winner to
`/output/entry.txt`.

The winning word is the account's own genuine handle:
`sukamtiindrawati-dot` (20 characters, one word, no spaces).

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
